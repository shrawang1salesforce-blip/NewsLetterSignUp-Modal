# Newsletter signup modal

A small HTML, CSS, and JavaScript exercise. The signup window appears after a short delay, and can also be opened from either signup button.

Open `index.html` in a browser to try it. Close the window with the close button, by clicking outside it, or with Escape. Once dismissed, it won't pop up automatically again in that browser.

The form checks that the address looks like an email, then shows a confirmation. It is a front-end demo; it does not send or store signups.
